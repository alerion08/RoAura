# Протокол оформления следующих инструкций RoAura

**Обязательный стандарт:** `template/style.json` версии `1.0.0`. Самостоятельно не менять дизайн.

1. Основа — **только реальная запись экрана RoAura**. Не генерировать заново элементы интерфейса ИИ.
2. Сохранять кадры оригинального приложения, за исключением двух утверждённых плашек.
3. Создать `examples/<instruction>.json` с темой и шагами: `title`, `start`, `end`, `text`.
4. Применять текущий `tools/render.py` и `template/style.json`.
5. Типографика: Montserrat ExtraBold 800 для заголовка и номера, Montserrat Medium 500 для описания.
6. Цвета: `#E0ECFA` фон; `#4176B8` контур и текст; `#4275B6` круг; `#FFFFFF` цифра.
7. Заголовок — верхняя закруглённая плашка с разделителем; описание — нижняя плашка с кругом шага.
8. Проверять переполнение текста; длинные инструкции сокращать либо разделять.
9. Экспортировать MP4 и GIF, сохранять исходное видео и JSON-сценарий отдельно.
10. Если пользователь меняет стиль — выпускать новую версию шаблона, не перекрашивать отдельные ролики.

Пиксельная идентичность PNG достигается при одинаковых кадрах, установленных шрифтах, версиях библиотек и настройках.
