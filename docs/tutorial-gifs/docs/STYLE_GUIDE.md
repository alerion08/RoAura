# RoAura — единый стиль GIF-инструкций (v1.0)

## Основа
Эталон — присланный пользователем скриншот 747 × 481. На настоящую видеозапись накладываются две светло-голубые плашки с синей обводкой: верхний заголовок и нижняя инструкция с круглым номером шага.

**Нельзя генерировать или заменять элементы интерфейса RoAura с помощью ИИ.** Центральная область — оригинальное видео. Цвета и геометрия фиксированы в `../template/style.json`.

## Цветовая палитра

| Элемент | HEX |
| --- | --- |
| Фон обеих плашек | `#E0ECFA` |
| Контур, разделители | `#4176B8` |
| Заголовок и текст инструкции | `#4176B8` |
| Круг с номером шага | `#4275B6` |
| Цифра шага | `#FFFFFF` |

Это единый набор цветов, выбранный по эталонному JPEG. Из-за сжатия JPEG отдельные пиксели оригинала могут отличаться.

## Шрифты

- **Montserrat ExtraBold (800)** — название инструкции и цифра шага.
- **Montserrat Medium (500)** — описание текущего действия.
- Шрифт на эталонной ширине 747 px: заголовок **22 px**, номер **36 px**, описание **21 px** (адаптивно до **16 px**, не больше 2 строк).
- Файлы шрифтов не распространять в репозитории. Использовать одинаковые версии шрифтов для идентичных рендеров.

## Геометрия, px при размере 747×481

Все размеры масштабируются по ширине `W/747`. Для другого соотношения сторон исходник сначала кадрируется.

**Верхняя плашка:** x=29, y=16, высота=54, скругление=27, обводка=2; ширина динамическая, минимум=345, максимум=689; вертикальный разделитель x=59 (y=28–55), толщина=2; текст начинается x=80.

**Нижняя плашка:** x=24, отступ справа=24, снизу=18, высота=86, скругление=43, обводка=2. Центр круга x=81, y=420, радиус=27. Разделитель x=123 с отступами 17 сверху и снизу, толщина=3. Текст начинается x=182, справа минимум=32. Вертикальная центровка.

## Текст

- Заголовок — тема, например «Добавление эффекта» или «Запуск MVP-таймера».
- Описание шага — одно действие в повелительном наклонении.
- В круге показывать только номер шага, **не** «3/6».
- Максимум две строки Medium; если текст не помещается даже при 16 px, разбить шаг или сократить подпись.
- При смене шага изменяются только текст описания и цифра.

## Вывод и проверка

- Основной формат: MP4 (меньше размер и лучше сохранение цвета).
- GIF для интерфейсов, где нужен зацикленный ролик, по умолчанию 8 fps.
- Два запуска с идентичным входным кадром и шрифтами/Pillow должны давать одинаковый PNG.
- Не менять вручную цвета и расположение отдельных инструкций.
- При согласованном изменении дизайна выпускать новую версию `style.json`, не переопределять v1.0.
