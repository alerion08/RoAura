## Второй набор — идеи 101–200

Каждая строка — одна задача. Номера соответствуют исходным разделам чек-листа. Отметка означает, что изменения внесены в код.

- [x] Поиск и карточки (103, 105, 106, 108, 109). Связки и слоты из описаний, сворачиваемый текст, возврат к позиции прокрутки, подсказка при опечатке.
- [x] Магазины и наблюдение (111). Закупка по бюджету.
- [x] Избранное (123, 126, 129). Заметка, цвет списка, счётчики типов.
- [x] План фарма (143, 145, 147, 148). Несколько монстров, источник оценки, сохранение плана в сессии, сравнение с добычей.
- [x] Таймеры (154, 155, 158). Пересечения окон, время ожидания на маршруте, секунды ближе к завершению.
- [x] Эффекты и напоминания (167). Дублирование эффекта с независимыми настройками персонажей и новым ID.
- [x] Gold Goblin и статистика (173, 174, 177). Ретрооценка, история ручных цен, заметка о сессии.
