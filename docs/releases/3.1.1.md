# RoAura 3.1.1

## Русский

Исправлена неполная публикация функций персонажа в 3.1.0. Обычная сборка теперь наблюдает вход персонажа в игру, показывает активный сервер и CID, хранит отдельную статистику Base/Job EXP, Zeny, предметов и времени для каждого подтверждённого персонажа. Gold Goblin и показатели скорости используют ту же сессию; сохранённую историю можно просмотреть без переключения источника игровых пакетов.

Определение CID требует, чтобы RoAura наблюдала пакет входа на карту. Если приложение запущено уже после входа, статистика остаётся без привязки до следующего входа. Данные сохраняются в `%LOCALAPPDATA%\RoAura\CharacterStatistics`; история отдельных DEV-сборок остаётся в `%LOCALAPPDATA%\RoAura-Dev\CharacterStatistics` и автоматически не переносится. Настройки и пресеты 3.1.0 сохраняются.

Сборка для Windows x64: `RoAura-3.1.1-portable.zip` или `RoAura-3.1.1-Setup.exe`. Требуется Npcap: https://npcap.com/#download. Закройте прежний процесс перед обновлением.

## English

This release completes the character features omitted from the regular 3.1.0 build. The regular build now observes map login, shows the active server and CID, and records separate Base/Job EXP, Zeny, loot and active time per verified character. Gold Goblin and rate overlays use the same session; saved history is read-only and does not select a packet owner.

CID detection requires RoAura to observe map login. If started after login, character statistics stay unattributed until the next login. Records are saved under `%LOCALAPPDATA%\RoAura\CharacterStatistics`; separate DEV history under `%LOCALAPPDATA%\RoAura-Dev\CharacterStatistics` is not automatically imported. Existing settings and presets are retained.

Windows x64: `RoAura-3.1.1-portable.zip` or `RoAura-3.1.1-Setup.exe`. Npcap is required: https://npcap.com/#download. Close the previous process before updating.
