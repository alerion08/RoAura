# RoAura 3.1.0

## Русский

- Для SpringRO распознавание Status ID теперь использует декодированные клиентом события включения и снятия статуса. Длительность берётся из события сервера; напоминания и панели эффектов используют тот же общий тракт.
- Подтверждение AID персонажа из игровых пакетов применяется к обучению Skill ID и Status ID и к показу эффектов SpringRO.
- Исправлена перезапись времени Hiding резервным событием без длительности.
- Существующие кулдауны, экипировка и другие профили сервера сохраняют прежнюю обработку.

Для декодирования требуется поддерживаемый `SpringRO.exe` и доступ к его памяти на чтение. При другом файле клиента или недоступном чтении события статусов не будут угаданы по преобразованным сетевым полям. Долгая игровая сессия, переподключение и нагрузка на процессор требуют дальнейшего наблюдения; текущая версия предварительно проверена пользователем в игре.

Закройте прежнюю RoAura перед установкой. Portable: `RoAura-3.1.0-portable.zip`; установщик: `RoAura-3.1.0-Setup.exe`. Нужен Npcap: https://npcap.com/#download. Настройки и пресеты остаются в `%APPDATA%\RoAura`.

## English

- SpringRO status activation and removal now use client-decoded Status IDs. Server durations feed the existing effect and reminder pipeline.
- Verified player AID is used for SpringRO Skill ID and Status ID learning and status attribution.
- A durationless Hiding fallback no longer overwrites a decoded timer.
- Existing cooldown, equipment and other server-profile handling is preserved.

The decoder requires the supported `SpringRO.exe` and read access to its process. A different client executable or denied read access cannot be recovered by guessing transformed network fields. Long-session stability, reconnect behavior and CPU usage still need observation; the current DEV behavior was provisionally accepted in game.

Close the previous RoAura before installing. Use `RoAura-3.1.0-portable.zip` or `RoAura-3.1.0-Setup.exe`. Npcap is required: https://npcap.com/#download. Settings and presets remain under `%APPDATA%\RoAura`.
