# RoAura 3.2.0

## Русский

- **Tides of Comodo (ToC):** выбор сервера, компактная локальная база из 9 894 предметов,
  1 061 монстра и 61 MVP. Характеристики оформлены таблицами, описания навыков свёрнуты.
  Данные респавна MVP взяты с официальных страниц карт и доступны в БД и подсказках таймеров.
- **Настройки:** кнопка в шапке открывает основные параметры, все горячие клавиши,
  менеджер персонажей и управление видимостью левого меню. «Другой» всегда последний.
- **Персонажи и оверлеи:** определённым CID можно назначить имя и сервер; каждый оверлей
  можно привязать к одному или нескольким персонажам. Без выбранных персонажей сохраняется
  прежнее поведение. Привязанные оверлеи требуют определённого совпадающего сервера/CID.
- **Кулдауны:** мастер определяет Skill ID до создания; отмена не оставляет лишний оверлей.
- **Чтение пакетов:** предупреждение и общий переключатель на главной. Отключение останавливает
  чтение и блокирует зависимые разделы; локальная БД и ручные MVP-таймеры доступны без захвата.
  Недоступные разделы остаются серыми. Пользователь может скрыть доступные пункты меню.
- **Оформление:** единые подсказки оверлеев, упорядоченные пустые области и цвет текста;
  иконка «О программе» всегда цветная.
- **Gold Goblin ToC:** NPC и ручные цены; маркет и отслеживание магазинов остаются функциями SpringRO.
  Таймеры и ценовые правила хранятся отдельно для серверов. Существующие настройки, пресеты
  и координаты сохраняются; имена персонажей не стираются при смене пресета.

### Установка и ограничения

Windows x64: `RoAura-3.2.0-portable.zip` или `RoAura-3.2.0-Setup.exe`.
Перед обновлением полностью закройте прежнюю RoAura. Настройки: `%APPDATA%\RoAura`,
статистика: `%LOCALAPPDATA%\RoAura\CharacterStatistics`. Npcap: https://npcap.com/#download.
Чтение пакетов может противоречить правилам сервера; переключатель доступен на главной.
Определение CID требует наблюдения входа на карту: запустите RoAura до входа или перезайдите.
Если источник не публикует респавн, интервал остаётся неизвестным. Сохранённые длительности
таймеров не заменяются автоматически данными карт.

Проверки Windows включают 233 теста приложения, запуск portable и сборку установщика;
импортёр и база проверяются восемью Python-тестами и проверкой целостности/контрольной суммы.
Новые функции ToC, привязки при релоге/нескольких клиентах и оформление при разных DPI
ещё требуют проверки в игре. Специальный декодер протокола ToC не добавлялся.

## English

- Added **Tides of Comodo (ToC)** with a compact offline catalog: 9,894 items, 1,061 monsters
  and 61 MVPs. Structured item/monster cards, collapsed skill descriptions, and published
  map-based MVP respawn details in Database and timer hints.
- The header **Settings** button opens General, all hotkeys, Character Manager and navigation
  visibility. Other is always last in server selectors.
- Assign names/servers to detected CIDs and select one or several characters for each overlay.
  Empty targeting retains legacy behavior; targeted overlays require an observed matching server/CID.
- The cooldown wizard learns Skill ID before creation; cancellation does not create an overlay.
- Home now explains packet reading and provides a global switch. Disabled features stay gray;
  offline Database and manual MVP timers work without capture. Available menu entries can be hidden.
- Unified overlay help cards, empty states and text colors; the About icon stays colored.
- ToC Gold Goblin uses NPC/manual valuation. Market/watch features remain SpringRO-only.
  Server-specific timers/rules, existing settings, presets and coordinates are retained;
  character aliases survive preset changes.

Windows x64: `RoAura-3.2.0-portable.zip` or `RoAura-3.2.0-Setup.exe`. Close the previous process
before updating. Settings stay in `%APPDATA%\RoAura`, history in
`%LOCALAPPDATA%\RoAura\CharacterStatistics`. Npcap: https://npcap.com/#download.
Packet reading may conflict with server rules. CID detection requires observing map login.
Unpublished respawns remain unknown; saved timer durations are not automatically overwritten.

Windows regression covers 233 app tests, portable startup and installer packaging; eight Python
tests and integrity/checksum checks cover the catalog. ToC gameplay, targeted overlays during
relog/multiple clients and DPI appearance still require manual acceptance. No custom ToC
protocol decoder is claimed.
