# Офлайн-база Ragnarok+ для RoAura

Сборщик запускается отдельно от RoAura. Нужны Python 3.10+ и Chrome или Edge.
Запускайте команды в PowerShell из корня репозитория.

```powershell
py -m pip install playwright Pillow
py tools/collect_ragnarokplus.py --channel msedge --browser-data "$env:LOCALAPPDATA\RoAuraCatalogBrowser" --output "$env:USERPROFILE\RoAuraCatalog"
```

Для Chrome укажите `--channel chrome`. При первом запуске войдите на сайт
в открывшемся окне браузера, затем нажмите Enter в терминале. При прерывании
запустите ту же команду. Сохранённые карточки с изображениями будут использованы
повторно, карточки без изображения будут проверены снова.

В выходной папке появится `ragnarokplus-offline.zip` со снимком каталога и
`coverage.json`. В отчёте указаны число карточек, отсутствующие изображения
и ссылки на записи вне выгрузки. Если число карточек расходится с числом
в каталоге сайта, сборщик завершится с ошибкой.

Для включения в сборку распакуйте `Data/database.ragnarokplus.json` поверх
одноимённого файла в RoAura из ветки с поддержкой локальных изображений.
Проверьте на чистой установке без сети карточки предметов, монстров и карт,
дроп, локации и изображения. В выходной архив браузерный профиль не входит.
